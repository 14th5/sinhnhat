# Món Quà Nhỏ

Mở bằng VSCode + extension **Live Server** (bấm "Go Live"). Không mở trực tiếp file index.html vì trình duyệt chặn ES module.

- `js/config.js` : sửa chữ, ảnh quả cầu, nội dung thư, nhạc, bật/tắt hiệu ứng
- `js/main.js`   : toàn bộ logic hạt, quả cầu, lá thư
- `js/music.js`  : nhạc nền
- `css/`         : base / start / sphere / letter
- `assets/`      : chép thư mục assets gốc của bạn vào đây (giữ nguyên tên file)
- `musics/`      : đặt file mp3
